# راه‌اندازی افغان کانکت در لپ‌تاپ دیگر (بدون pgAdmin)

## نکته مهم
pgAdmin خودِ دیتابیس نیست؛ فقط ابزار گرافیکی مدیریت PostgreSQL است. برای اجرای پروژه، PostgreSQL Server لازم است، اما نصب pgAdmin ضروری نیست. ساده‌ترین روش برای ارائه، اجرای همه بخش‌ها با Docker Compose است.

## پیش‌نیاز
1. نصب Docker Desktop روی ویندوز لپ‌تاپ هم‌صنفی.
2. بازکردن Docker Desktop و صبر تا وضعیت آن Running شود.
3. استخراج کامل ZIP پروژه در یک پوشه.

## اجرا
روی فایل `RUN_PROJECT_WINDOWS.bat` دوبار کلیک کنید؛ یا در ترمینال همان پوشه اجرا کنید:

```bash
docker compose up --build
```

در اولین اجرا، Docker ایمیج‌ها را دریافت می‌کند و ممکن است چند دقیقه زمان ببرد. PostgreSQL به‌صورت خودکار ساخته می‌شود و `database/schema.sql` و سپس `database/seed.sql` فقط هنگام ایجاد دیتابیس خالی اجرا می‌شوند.

پس از آماده‌شدن سرویس‌ها:
- فرانت‌اند: http://localhost:5173
- بک‌اند: http://localhost:5000
- بررسی سلامت API: http://localhost:5000/api/v1/health
- PostgreSQL: localhost:5432 (نام دیتابیس `afghan_connect`)

برای توقف، `STOP_PROJECT_WINDOWS.bat` یا `docker compose down` را اجرا کنید. برای حفظ داده‌ها از `docker compose down -v` استفاده نکنید؛ گزینه `-v` دیتابیس را پاک می‌کند.

## اگر Docker در دسترس نبود
باید PostgreSQL Server 14 یا جدیدتر را جداگانه نصب و اجرا کنید، سپس `schema.sql` و `seed.sql` را یک بار روی دیتابیس خالی `afghan_connect` اجرا کنید. pgAdmin اختیاری است؛ به‌جای آن می‌توان از `psql` استفاده کرد. در این حالت متغیرهای اتصال فایل `backend/.env` باید با مشخصات همان لپ‌تاپ تنظیم شوند و فرانت‌اند و بک‌اند با `npm install` و `npm run dev` اجرا شوند.

## نکات امنیتی
تنظیمات داخل Compose فقط برای اجرای محلی و ارائه در صنف است. رمزها و کلید JWT نمونه‌اند و برای انتشار عمومی یا میزبانی اینترنتی مناسب نیستند. فایل‌های `.env` واقعی را با دیگران شریک نسازید.
